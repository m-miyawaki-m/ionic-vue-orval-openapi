# P4 境界値ジェネレータ (gen-cases) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`).

**Goal:** 設計ソース（OpenAPI契約 ＋ CSV画面項目定義書）から境界値テストケースを自動生成し、正準 `frontend/tests/cases/*.cases.json` とデータ駆動Vitest、整合性レポート `docs/spec-src/reconcile.md` を出力する。イベント定義/ストア定義CSVも読み、操作系/状態遷移のテスト項目を（非実行の文書項目として）cases.jsonに含める。

**Architecture:** 境界値導出ロジックはTSに一本化（`scripts/gen-cases/`）。アダプタ方式で OpenAPI と CSV の2ソースから「フィールド制約記述子」を取り出し、共通の `deriveBoundaryCases()` でケース化。出力 `cases.json` が「実行テスト」と（P5の）「仕様書/Excel」両方の単一の真実。データ駆動テストは group→zodスキーマ の小さなレジストリで各ケースを検証（OK期待=safeParse成功 / NG期待=失敗）。

**Tech Stack:** TypeScript / tsx / js-yaml / zod / Vitest（すべてP1で導入済み）

前提（P1/P2で確定）:
- `openapi/openapi.yaml`（リポジトリ root）に ItemInput（name 1-30, price 0-1000000, category enum food|drink|other, code ^[A-Z0-9]{8}$）と LoginRequest（username 3-20, password 8-64）の制約あり。各プロパティに `example` あり。
- 画面バリデータ: `frontend/src/validators/item.ts`（`itemInputSchema`）, `frontend/src/validators/auth.ts`（`loginSchema`）。
- `js-yaml`/`@types/js-yaml`/`tsx` は devDeps 済み。Vitest jsdom 設定済み。`npm run gen:cases` 用に package.json にスクリプト追加。
- gen-cases は `frontend/` を cwd に実行する想定。パス: openapi=`../openapi/openapi.yaml`、CSV=`../docs/spec-src/...`、出力=`tests/cases/`。

export interface FieldConstraint {
  group: string          // 'item' | 'login'（論理エンティティ）
  field: string          // 'name' 等
  type: FieldType
  required: boolean
  minimum?: number
  maximum?: number
  minLength?: number
  maxLength?: number
  enumValues?: string[]
  pattern?: string
  example: string | number // 妥当な代表値（pattern/enum検証の有効例にも使う）
}

export interface BoundaryCase {
  value: unknown          // 境界値（absent の場合は __ABSENT__）
  expectValid: boolean
  label: string           // 'minLength-1', 'enum:food' 等
}

export const ABSENT = '__ABSENT__' as const

export interface CaseRecord {
  id: string              // 一意（例: 'bnd:openapi:item:name:minLength-1'）
  source: 'openapi' | 'field-spec'
  kind: 'boundary'
  group: string
  field: string
  value: unknown
  expectValid: boolean
  label: string
}

export interface DocItem {
  id: string
  source: 'event-spec' | 'store-spec'
  kind: 'operation' | 'state'
  group: string           // screen or store name
  description: string     // 観点
  precondition: string
  action: string
  expected: string
}

- [ ] **Step 3: 実装** `frontend/scripts/gen-cases/boundary.ts`:
```ts
import { ABSENT, BoundaryCase, FieldConstraint } from './types'

export function deriveBoundaryCases(c: FieldConstraint): BoundaryCase[] {
  const cases: BoundaryCase[] = []

  if (c.type === 'integer' || c.type === 'number') {
    if (c.minimum !== undefined) {
      cases.push({ value: c.minimum - 1, expectValid: false, label: 'minimum-1' })
      cases.push({ value: c.minimum, expectValid: true, label: 'minimum' })
    }
    if (c.maximum !== undefined) {
      cases.push({ value: c.maximum, expectValid: true, label: 'maximum' })
      cases.push({ value: c.maximum + 1, expectValid: false, label: 'maximum+1' })
    }
  }

  if (c.type === 'string') {
    const ch = 'a'
    if (c.minLength !== undefined) {
      cases.push({ value: ch.repeat(Math.max(0, c.minLength - 1)), expectValid: c.minLength - 1 >= (c.minLength), label: 'minLength-1' })
      // minLength-1 is always invalid when minLength>=1; fix expectValid explicitly:
      cases[cases.length - 1].expectValid = (c.minLength - 1) >= c.minLength ? true : false
      cases.push({ value: ch.repeat(c.minLength), expectValid: true, label: 'minLength' })
    }
    if (c.maxLength !== undefined) {
      cases.push({ value: ch.repeat(c.maxLength), expectValid: true, label: 'maxLength' })
      cases.push({ value: ch.repeat(c.maxLength + 1), expectValid: false, label: 'maxLength+1' })
    }
    if (c.enumValues) {
      for (const v of c.enumValues) cases.push({ value: v, expectValid: true, label: `enum:${v}` })
      cases.push({ value: '__invalid_enum__', expectValid: false, label: 'enum:invalid' })
    }
    if (c.pattern) {
      cases.push({ value: String(c.example), expectValid: true, label: 'pattern:valid' })
      cases.push({ value: '!!', expectValid: false, label: 'pattern:invalid' })
    }
  }

  if (c.required) {
    cases.push({ value: ABSENT, expectValid: false, label: 'required-absent' })
  }

  return cases
}
```
**注意:** 上記の `minLength-1` の expectValid は「minLength>=1 のとき常に false」。実装では単純に `false` を設定すること（テストは length 0 → invalid を期待）。冗長な自己代入行は消し、`expectValid: false` にする。最終形:
```ts
    if (c.minLength !== undefined) {
      cases.push({ value: ch.repeat(Math.max(0, c.minLength - 1)), expectValid: false, label: 'minLength-1' })
      cases.push({ value: ch.repeat(c.minLength), expectValid: true, label: 'minLength' })
    }
```
Run → PASS。

- [ ] **Step 2: cli 実装** `frontend/scripts/gen-cases/cli.ts`:
```ts
import fs from 'node:fs'
import path from 'node:path'
import { loadOpenapiConstraints } from './openapi-adapter'
import { loadCsvConstraints } from './csv-adapter'
import { loadDocItems } from './docItems'
import { deriveBoundaryCases } from './boundary'
import { buildReconcileMarkdown } from './reconcile'
import type { CaseRecord, FieldConstraint } from './types'

function toRecords(constraints: FieldConstraint[], source: CaseRecord['source']): CaseRecord[] {
  const out: CaseRecord[] = []
  for (const c of constraints) {
    for (const b of deriveBoundaryCases(c)) {
      out.push({
        id: `bnd:${source}:${c.group}:${c.field}:${b.label}`,
        source, kind: 'boundary', group: c.group, field: c.field,
        value: b.value, expectValid: b.expectValid, label: b.label,
      })
    }
  }
  return out
}

const openapi = loadOpenapiConstraints()
const csv = loadCsvConstraints()
const boundary: CaseRecord[] = [...toRecords(openapi, 'openapi'), ...toRecords(csv, 'field-spec')]
const docItems = loadDocItems()

const casesDir = path.resolve(process.cwd(), 'tests/cases')
fs.mkdirSync(casesDir, { recursive: true })
fs.writeFileSync(path.join(casesDir, 'boundary.cases.json'), JSON.stringify(boundary, null, 2) + '\n')
fs.writeFileSync(path.join(casesDir, 'doc.cases.json'), JSON.stringify(docItems, null, 2) + '\n')

const reconcileDir = path.resolve(process.cwd(), '../docs/spec-src')
fs.mkdirSync(reconcileDir, { recursive: true })
fs.writeFileSync(path.join(reconcileDir, 'reconcile.md'), buildReconcileMarkdown(openapi, csv))

console.log(`Generated ${boundary.length} boundary cases, ${docItems.length} doc items.`)
```
